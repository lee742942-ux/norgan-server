POST /api/v1/validate

Send raw prompt streams or rich JSON structure vectors to evaluate data security health values before sending payload inputs down to production LLMs.

// REQUEST BODY SCHEMAS
payload string (Required) — Raw prompt text or stringified JSON
stripPii boolean (Optional) — Redact sensitive identities. Default: true
promptShield boolean (Optional) — Block system bypass rules. Default: false
